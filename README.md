# sydanukrainalle.org

Website of Global Mine Action Hub, a program of Sydän Ukrainalle ry (Y-tunnus 3543515-1).

- `public/` — the website pages
- `src/worker.js` — callback form → Telegram
- `wrangler.jsonc` — Cloudflare settings

Every change pushed to the `main` branch is published automatically by Cloudflare.
